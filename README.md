This is a fully functional calculator application with some gestures made for fun :)

## Features

- Basic arithmetic operations: +, -, *, /
- Modulo operation (MOD)
- **XOR operation (bitwise exclusive OR)**
- Percentage calculation (%)
- Sign toggle (+/-)
- Decimal number support
- Gesture-based activation (tap AC button 3 times)
- Landscape mode help section

## New in this version
- Added XOR operation for bitwise exclusive OR calculations
